## Q1. Streamlit을 사용해서 AI 모델을 웹 애플리케이션에 통합하는 단계

**한 줄 요약**
- Streamlit으로 AI 모델을 통합할 때는 모델 캐싱(로드), 전처리/유효성 검사(입력 처리), 시각화/후처리(결과 출력)의 3단계 파이프라인을 구축해야 합니다.

**자세한 설명**
* **모델 로드:** 매번 모델을 불러오는 성능 저하를 막기 위해 `@st.cache_resource` 등의 데코레이터를 사용하여 앱 시작 시 한 번만 메모리에 올립니다.
* **사용자 입력:** 텍스트 토큰화, 이미지 리사이징 등 모델이 이해할 수 있게 입력을 전처리하고, 잘못된 값이 들어오지 않도록 예외 처리 및 유효성을 검사합니다.
* **결과 출력:** 모델의 예측 결과를 `st.write`, `st.image`, `st.bar_chart` 등 Streamlit의 시각화 컴포넌트를 활용해 사용자 친화적인 텍스트나 그래픽으로 후처리하여 화면에 띄워줍니다.


**예시 / 비유**
- 붕어빵 장사(웹 앱)에 비유할 수 있습니다. 무겁고 달구기 힘든 무쇠틀(모델)은 장사 시작 때 한 번만 달궈두고(모델 로드)**, 손님이 주문한 밀가루와 팥을 알맞게 반죽해 틀에 부으며**(입력 처리)**, 다 구워진 붕어빵을 먹기 좋게 예쁜 봉투에 담아 건네주는**(결과 출력) 과정과 완벽히 일치합니다.

## Q2. FastAPI를 활용한 AI 모델 웹 API 서버 코드 구조

**한 줄 요약**
- FastAPI를 활용한 AI 서버는 **엔드포인트(Routers), 데이터 검증(Models), 추론 비즈니스 로직(Services), 보조 기능(Utils)** 등 역할(관심사)별로 디렉토리를 분리해 모듈화하는 것이 핵심입니다.

**자세한 설명**
* `main.py`: 서버의 진입점으로 FastAPI 앱을 생성하고 전역 설정 및 라우터들을 연결합니다.
* `routers/`: `/predict` 등 URL 경로별로 사용자 요청을 어떻게 받을지 엔드포인트를 정의합니다.
* `models/`: Pydantic을 활용해 입력(Request)과 출력(Response) 데이터의 형태와 유효성을 자동 검증합니다.
* `services/` (또는 `core/`): AI 모델을 로드하고 실제 추론을 수행하는 핵심 로직이 위치합니다.
* `utils/`: 이미지/텍스트 전처리나 로그 기록 등 기타 보조 기능을 따로 모아 유지보수성을 높입니다.


**예시 / 비유**
- 분업화가 잘 된 대형 레스토랑의 주방 시스템과 같습니다. `main.py`는 식당 문을 열고 총괄하는 매니저, `routers`는 손님의 주문을 받는 홀 직원, `models`는 주문서 양식이 정확한지 확인하는 포스(POS)기, `services`는 주문을 받아 실제 요리를 만들어내는 메인 셰프(AI 모델), `utils`는 재료 손질과 설거지를 돕는 보조 요리사입니다.

## Q3. 현존하는 AI 웹/앱 서비스 전체 아키텍처 설계 (VoiceSummarizer)

**한 줄 요약**
- 가상의 음성 요약 서비스 'VoiceSummarizer'는 Streamlit(프론트) - FastAPI(백엔드) - Docker(독립 환경) - ONNX/TensorRT(추론 최적화)가 결합된 비동기 기반 클라우드 아키텍처로 구현됩니다.

**자세한 설명**
* **전체 흐름 & 최적화:** 사용자가 Streamlit에서 음성을 업로드하면, FastAPI 서버가 이를 받아 ONNX 및 TensorRT로 최적화된 모델을 통해 GPU 환경에서 빠르게 텍스트로 변환하고 요약합니다.
* **멀티유저 & 비동기:** 파일 처리 시간이 긴 음성 데이터 특성상, 요청이 몰릴 경우 비동기 처리 및 작업 큐(Redis + Celery)를 활용해 병목 현상을 방지합니다.
* **인프라 & 보안:** 모든 구성 요소(웹, API, 모델)는 개별 Docker 컨테이너로 격리되어 GCP(구글 클라우드) 인프라 위에 배포되며, CORS 설정과 Let's Encrypt HTTPS로 보안을 통제합니다.
* **모니터링:** Prometheus와 Grafana로 서버 상태를 실시간 시각화하고, 구조화된 로깅과 Sentry를 통해 에러를 추적해 사용자 경험을 지속적으로 개선합니다.


**예시 / 비유**
- 거대한 자동화 공장(클라우드) 안에 있는 번역 센터와 같습니다. 고객이 '접수 창구(Streamlit)'에 녹음기를 맡기면, '작업 반장(FastAPI)'이 대기줄(작업 큐)에 순서대로 세웁니다. '초고속 번역 기계(Docker 방 안의 최적화된 AI)'가 작업을 마치면 결과를 다시 앞단으로 보내줍니다. 허가받지 않은 외부인의 접근은 철저히 막히며(CORS/HTTPS), 공장 벽에는 기계들이 고장 없이 잘 돌아가는지 보여주는 커다란 계기판(Grafana)이 실시간으로 돌아가고 있는 모습입니다.
