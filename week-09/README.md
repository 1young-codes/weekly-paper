## Q1. BERT와 GPT의 주요 차이점은 무엇인가요? (구조, 작동 방식, 응용 분야)

**한 줄 요약:** BERT는 Transformer의 인코더만 써서 문장을 양방향으로 이해하는 데 특화된 모델이고, GPT는 디코더만 써서 왼쪽에서 오른쪽으로 다음 단어를 생성하는 데 특화된 모델이다.

**자세한 설명**

구조와 작동 방식
- **BERT (인코더 기반):** Transformer의 인코더만 사용한다. 입력 문장 전체를 양방향(Bidirectional)으로 동시에 보며 문맥을 파악한다. 사전학습은 문장 일부 단어를 가리고 맞히는 Masked Language Modeling(MLM)과, 두 문장이 이어지는지 판단하는 Next Sentence Prediction(NSP)으로 진행된다.
- **GPT (디코더 기반):** Transformer의 디코더만 사용한다. 왼쪽에서 오른쪽으로 한 방향(Unidirectional)으로만 보며, 앞의 단어들만 근거로 다음 단어를 예측하는 자기회귀(Autoregressive) 방식으로 사전학습된다. 이때 뒤에 올 단어를 미리 보지 못하도록 마스킹된(causal) 셀프 어텐션을 쓴다.
- 참고로 인코더와 디코더를 모두 쓰는 세 번째 갈래도 있다. T5가 대표적이며, 번역처럼 입력과 출력이 모두 필요한 과제에 자연스럽게 맞는다. (Q3에서 다룸)

응용 분야
- **BERT는 언어 이해(understanding) 중심:** 문서 분류, 문장 유사도 판단, 개체명 인식(NER), 질의응답처럼 의미를 해석하는 작업에 강하다.
- **GPT는 언어 생성(generation) 중심:** 텍스트 자동 완성, 대화 응답, 요약, 창작, 코드 생성처럼 문장을 만들어내는 작업에 강하다.

정리
- BERT는 인코더 기반으로 문장을 이해하는 데 최적화되어 있고, GPT는 디코더 기반으로 문장을 생성하는 데 강점이 있다.

**예시 / 비유**

- BERT는 빈칸 채우기 시험을 푸는 사람과 같다. 빈칸의 앞뒤를 모두 읽고 문맥으로 답을 맞힌다. GPT는 이야기를 이어 쓰는 사람과 같다. 지금까지 쓰인 문장만 보고 다음 문장을 만들어낸다.

## Q2. Hugging Face Transformers 라이브러리는 무엇이며, 어떤 기능을 제공하나요?

**한 줄 요약:** Hugging Face Transformers는 사전학습된 자연어처리 모델을 몇 줄의 코드로 불러와 사용하고 미세조정까지 할 수 있게 해주는 오픈소스 라이브러리로, NLP 실무의 생산성과 접근성을 크게 높여준다.

**자세한 설명**

핵심 성격
- PyTorch와 TensorFlow를 모두 지원하며, BERT, GPT, RoBERTa, T5, DistilBERT 같은 유명 모델을 직접 구현하지 않고도 바로 가져다 쓸 수 있다. 덕분에 모델 실험과 응용을 빠르게 진행할 수 있다.

주요 기능
1. **사전학습 모델 로딩과 추론:** AutoTokenizer와 AutoModel로 모델을 불러오거나, pipeline 기능을 쓰면 토크나이징부터 추론까지 한 번에 처리된다.
2. **다양한 NLP 과제의 통합 지원:** 문서 분류, 감성 분석, 개체명 인식, 질의응답, 요약, 번역, 텍스트 생성 등을 일관된 인터페이스로 다룰 수 있다.
3. **미세조정(Fine-Tuning):** Trainer 클래스를 활용하면 사용자 데이터에 맞춰 사전학습 모델을 미세조정할 수 있고, 데이터 준비부터 학습, 평가, 저장까지 간편하게 구성된다.
4. **주변 생태계와의 연동:** datasets 라이브러리로 공개 데이터셋을 빠르게 불러오고, Model Hub를 통해 전 세계 사용자가 올린 수많은 사전학습 모델을 검색해 활용할 수 있다.

**예시 / 비유**

- 요리에 비유하면, 재료 손질부터 조리까지 직접 하는 대신 잘 만들어진 밀키트를 골라 데우기만 하면 되는 것과 같다. 모델이라는 복잡한 재료를 처음부터 구현하지 않고, 검증된 것을 불러와 내 데이터에 맞게 살짝 조리(미세조정)하기만 하면 된다.

## Q3. BERT와 GPT 이후 등장한 주요 사전학습 모델과 그 특징

**한 줄 요약:** BERT와 GPT 이후의 흐름은 학습 방법을 다듬어 성능을 끌어올리고(RoBERTa), 모델 규모를 키워 범용성을 확보하고(GPT-3), 이후 과제 통합(T5), 정렬(RLHF), 오픈 모델(LLaMA), 추론 모델로 이어지며 빠르게 발전해왔다.

**자세한 설명**

배운 모델

1. RoBERTa (Robustly Optimized BERT Approach)
- BERT와 구조는 같지만 학습 방법을 개선해 성능을 끌어올린 모델이다.
- NSP 과제를 제거하고 순수한 Masked Language Modeling만 사용했으며, 더 많은 데이터와 더 긴 학습 시간, 더 큰 배치 크기를 썼다.
- 구조 변경 없이 학습 설정만 정교하게 바꿔도 대부분의 NLP 과제에서 성능이 오른다는 것을 보여줬다.

2. GPT-2 / GPT-3
- OpenAI가 발표한 대규모 언어 생성 모델 계열이다.
- GPT-2는 15억(1.5B), GPT-3는 1,750억(175B) 파라미터 규모다.
- 별도의 미세조정 없이 사전학습만으로도 few-shot 및 zero-shot 학습이 가능하다는 것을 보여줬고, 단일 모델로 다양한 생성 작업을 수행하는 높은 범용성을 입증했다.

2020년 이후 등장한 모델들

- **T5 (2020, Google):** 인코더와 디코더를 모두 쓰는 구조로, 모든 과제를 "텍스트 입력 → 텍스트 출력"이라는 하나의 틀로 통합했다. BERT의 단어 단위 마스킹과 달리 여러 단어 구간을 통째로 가리는 span corruption으로 사전학습한다. 이렇게 통합하면 과제마다 다른 출력 구조나 별도의 출력층을 설계할 필요 없이, 같은 모델과 같은 손실 함수로 번역과 요약과 분류와 질의응답을 모두 학습하고 미세조정할 수 있다. 파이프라인이 단순해지고 여러 과제를 함께 학습시켜 지식을 공유하기도 쉬워진다.

- **정렬(Alignment)의 등장 — InstructGPT / ChatGPT (2022):** 다음 단어 예측만 하던 모델을, 사람이 원하는 방식으로 답하도록 지도 미세조정(SFT)과 인간 피드백 기반 강화학습(RLHF)으로 다듬은 흐름이다. 다음 단어 예측만으로 학습한 모델은 그럴듯한 문장은 잘 만들지만, 그럴듯함이 곧 사용자가 원하는 유용하고 정확한 답인 것은 아니다. RLHF는 이 간극을 메운다. 먼저 사람이 쓴 모범 답변으로 지도 미세조정을 하고, 이어 사람이 여러 답변의 우열을 매긴 데이터로 보상 모델을 학습시킨 뒤, 그 보상을 높이는 방향으로 강화학습을 돌린다. 그 결과 모델은 통계적으로 그럴듯한 텍스트가 아니라 사람이 실제로 선호하는 답을 내도록 정렬된다.

- **오픈 모델 — LLaMA 계열 (Meta, 2023~):** 더 적은 파라미터로 높은 효율과 접근성을 추구한 오픈 모델이다. 가중치가 공개되면 API 비용이나 특정 회사 종속 없이 누구나 모델을 직접 실행하고 뜯어보고 미세조정할 수 있다. 데이터를 외부로 보내지 않고 로컬에서 돌려 프라이버시를 지킬 수 있고, 연구자와 소규모 팀이 특정 도메인에 맞춰 개조하거나 편향과 안전성을 감사할 수 있다. 소수 기업만 최첨단 모델을 쥐던 구조를 열어 연구와 응용의 저변을 넓혔다는 점에서 중요하다.

- **추론 모델 (Reasoning models, 2024~):** 답을 바로 생성하지 않고 내부적으로 사고 과정을 거쳐 문제를 푸는 계열이다. 일반 모델은 질문을 받으면 곧바로 답을 토큰 단위로 뱉지만, 추론 모델은 최종 답을 내기 전에 사고 사슬(chain-of-thought)을 펼쳐 중간 단계를 밟고 필요하면 스스로 오류를 고친다. 어려운 문제일수록 생각에 더 많은 연산을 쓴다. 그 대신 답까지 시간이 더 걸리고 비용이 크지만, 수학이나 논리처럼 여러 단계를 밟아야 하는 문제에서 특히 강하다.

- **효율화 — Mixture of Experts(MoE):** 전체 파라미터 중 일부 전문가만 골라 활성화해, 규모를 키우면서도 연산 비용을 억제하는 기법이다. 일반(dense) 모델은 토큰 하나를 처리할 때 전체 파라미터를 모두 쓰지만, MoE는 여러 전문가 하위 네트워크를 두고 라우터가 토큰마다 그중 일부만 골라 활성화한다. 그래서 전체 파라미터, 즉 지식 용량은 크게 키우면서도 토큰당 실제 계산량은 작게 유지된다. 예를 들어 DeepSeek V3는 전체 671B 파라미터 중 토큰당 약 37B만 활성화한다. 큰 모델의 지식을 작은 모델의 연산 비용으로 쓰는 셈이다. 다만 전문가 간 부하를 고르게 맞추는 학습이 까다롭고, 전체 파라미터를 메모리에 올려둬야 하는 부담은 남는다.

**예시 / 비유**

- BERT와 GPT 이후의 발전은 한 명의 신입을 키우는 과정에 비유할 수 있다. 먼저 같은 교재로 더 오래 더 꼼꼼히 훈련시키고(RoBERTa), 아는 것을 폭발적으로 늘려 몸집을 키운 뒤(GPT-3), 아무리 똑똑해도 제멋대로면 곤란하니 사람 말을 잘 듣고 원하는 방식으로 답하도록 길들이고(RLHF), 나아가 즉답 대신 차근차근 생각한 뒤 답하도록 가르친다(추론 모델). 한편 모든 것을 혼자 다 아는 만능 직원 대신 분야별 전문가를 여럿 두고 질문마다 필요한 사람만 부르는 방식으로 조직을 효율화한 것이 MoE다.
